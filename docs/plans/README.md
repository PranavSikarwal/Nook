## Archived plans

`../archive/plans/` contains completed execution, release, migration, test, and
documentation-triage plans. These files are historical records. They do not
describe current system behavior.

`../archive/spec/` contains the retired version 1 specifications. The current
references are `../architecture.md`, `../contracts.md`,
`../tools-and-authorization.md`, `../release.md`, and `../testing.md`.
