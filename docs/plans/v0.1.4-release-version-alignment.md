# v0.1.4 release version alignment plan

## Purpose

Align Nook's application version metadata and release checklist before building
and publishing v0.1.4.

## Steps

1. Create a release branch from the merged `main` commit.
2. Update the application version in Tauri, Rust, npm, and both lockfiles.
3. Move the completed release notes from `Unreleased` into `v0.1.4` in
   `CHANGELOG.md`.
4. Document the required version files, changelog update, package run, and
   required PR checks in `CONTRIBUTING.md`.
5. Validate metadata consistency and run the relevant build checks.
6. Commit and push one PR containing the release version and contribution
   checklist changes.
7. Publish a tag only after that PR merges and a package run on the merged
   version passes all platform inspections.

## Done condition

The release PR keeps all application version metadata at `0.1.4`, documents the
release checks, and produces verified macOS, Ubuntu, and Windows packages before
any `v0.1.4` tag is created.
