# Documentation archive

This directory stores records that do not define current Nook behavior.

## Plans

`plans/` contains completed implementation, migration, release, and test plans.
They record earlier work and may reference retired file paths or behavior.

## Specifications

`spec/` contains the retired version 1 specifications. Several files describe
the former Swift Panel and earlier tool boundaries. Current references live in
`../architecture.md`, `../contracts.md`, `../tools-and-authorization.md`,
`../release.md`, and `../testing.md`.
